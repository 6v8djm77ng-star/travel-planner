# מתכנן הנסיעות שלי ✈️

אפליקציית ווב (PWA) לתכנון נסיעה לחו"ל מא׳ עד ת׳ — עברית מלאה, RTL, עובדת במחשב ובנייד וניתנת להתקנה על מסך הבית.

## מה יש בפנים

- **תכנון נסיעה** — עסקית (עם שם וכתובת תערוכה/כנס) או פרטית, תאריכים, נוסעים ומחלקה.
- **חיפוש טיסות בקישורים חכמים** — Google Flights, Skyscanner ו-Kayak נפתחים כשהם כבר מוגדרים: המראה מ-TLV (ברירת מחדל), התאריכים שלך, מחלקת עסקים/פרימיום, מיון לפי מחיר והעדפה לטיסות ישירות.
- **חיפוש מלון 5 כוכבים** — Booking.com (מסונן ל-5 כוכבים) ו-Google Hotels:
  - נסיעה **עסקית** → החיפוש ממוקד ליד כתובת התערוכה.
  - נסיעה **פרטית** → החיפוש ממוקד באזור המרכזי של העיר.
- **לו"ז יומי** — יום-יום עם שעות, קטגוריות (פגישות, אטרקציות, מסעדות, נסיעות) והערות.
- **תקציב** — הגדרת תקציב, רישום הוצאות לפי קטגוריה, בר ניצול והתראת חריגה.
- **מסמכים** — שמירת כרטיסים ואישורים (עד 2MB לקובץ) + צ׳ק-ליסט אריזה שנבנה אוטומטית לפי סוג הנסיעה.
- **תזכורות** — תזכורות אוטומטיות (צ׳ק-אין 24 שעות לפני, בדיקת דרכון, אריזה) + תזכורות אישיות, כולל התראות דפדפן.

כל המידע נשמר **מקומית במכשיר בלבד** (localStorage) — שום דבר לא נשלח לשרת.

## הפעלה

```bash
# מתוך שורש הריפו
npx serve travel-planner
# או
cd travel-planner && python3 -m http.server 8080
```

ואז לפתוח `http://localhost:8080` בדפדפן. בנייד: לפתוח את הכתובת ולבחור "הוסף למסך הבית" — האפליקציה תותקן כ-PWA ותעבוד גם אופליין.

> התקנת PWA והתראות דפדפן דורשות הגשה ב-HTTPS (או localhost).

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `js/links.js` | בניית קישורי חיפוש חכמים (טיסות ומלונות) — לוגיקה טהורה עם בדיקות |
| `js/storage.js` | שמירת נסיעות ב-localStorage |
| `js/app.js` | ממשק המשתמש (vanilla JS, ללא תלויות) |
| `sw.js` + `manifest.webmanifest` | תמיכת PWA ואופליין |
